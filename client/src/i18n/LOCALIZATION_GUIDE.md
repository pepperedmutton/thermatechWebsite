Multi-language implementation guide
===================================

Scope:
- Supported locales: zh-CN (default, no prefix), en (/en), ja (/ja), ru-RU (/ru).
- One JSON per page/namespace under `src/locales/<locale>/`.
- Keys must be identical across all locales. No empty translations allowed.

How to add translations for a page
----------------------------------
1. Pick a namespace name (e.g., `home`, `products`, `product_faraday`, `about`, `contact`, `news`, `sitemap`, etc.).
2. Create JSON files for **all** locales:
   - `src/locales/zh-CN/<namespace>.json`
   - `src/locales/en/<namespace>.json`
   - `src/locales/ja/<namespace>.json`
   - `src/locales/ru-RU/<namespace>.json`
3. Define structured keys (examples):
   - `meta.title`, `meta.description`, `meta.keywords`
   - `hero.title`, `hero.subtitle`, `hero.cta`
   - `section_core.heading`, `section_core.bullet_1`, etc.
   - `features.item_1.title`, `features.item_1.body`
4. Copy the zh-CN source text into the zh-CN file, then translate the values into en/ja/ru-RU with the same keys.
5. In components, use `const { t, locale } = useI18n();` and call `t('<namespace>.<path>', 'fallback')`. Avoid hardcoded text.

Locale-aware links
------------------
- Use `buildLocalizedPath(locale, pathname)` from `src/i18n/i18n.tsx` to generate URLs that keep the current route but switch locale.
- Prefer relative child paths in `routes.jsx`; top-level prefixes are already handled.
- In nav/footer/switcher, call `buildLocalizedPath(targetLocale, location.pathname)` when switching language.

HTML lang / SEO
---------------
- `I18nProvider` updates `<html lang>` on the client. For SSR/static, ensure the locale route renders the correct `lang`.
- Titles and descriptions should come from `t()`; add hreflang/canonical per locale variant in page head.

**Standard SEO implementation for each page:**
```jsx
import { buildCanonicalUrl, buildHreflangLinks, getOgLocale, getOgLocaleAlternates } from '../../i18n/seo';

const alternates = buildHreflangLinks('/your-path');
const canonical = buildCanonicalUrl(locale, '/your-path');
const ogLocale = getOgLocale(locale);
const ogAlternates = getOgLocaleAlternates(locale);

<Helmet>
  <title>{t('namespace.meta.title')}</title>
  <meta name="description" content={t('namespace.meta.description')} />
  <link rel="canonical" href={canonical} />
  {alternates.map((item) => (
    <link key={item.hreflang} rel="alternate" href={item.href} hreflang={item.hreflang} />
  ))}
  <link rel="alternate" href={buildCanonicalUrl('zh-CN', '/your-path')} hreflang="x-default" />
  
  <meta property="og:locale" content={ogLocale} />
  {ogAlternates.map((alt) => (
    <meta key={alt} property="og:locale:alternate" content={alt} />
  ))}
  <meta property="og:title" content={t('namespace.meta.title')} />
  <meta property="og:description" content={t('namespace.meta.description')} />
  <meta property="og:url" content={canonical} />
  <meta property="og:type" content="website" />
</Helmet>
```

Adding a new page
-----------------
1. Add routes only once under the localized route tree (see `routes.jsx`).
2. Create locale JSONs with keys for all visible text and SEO strings.
3. Replace literals in the component with `t()` lookups and locale-aware links.
